# 通用代理框架 (Abstract Agent Framework)

## 1. 架构定位
**Agent Framework（通用代理框架）** 是现代基于大模型（LLM）的智能系统中的核心抽象引擎。它负责调度大语言模型与各个底层组件，是所有具体化物理引擎（如 Opencode、Claude Code 等）的基类。

## 2. 核心组件
无论具体的实例化框架如何设计，一个标准的 Agent Framework 通常协调以下核心组件：

- **LLM (Large Language Model)**: 认知核心，提供基础的意图理解和逻辑推理能力。框架连接到 LLM 端点以分析上下文并做出工具调用决策。
- **Tool (工具)**: 框架将 LLM 的意图转化为具体的平台工具调用（如终端命令、文件读写等具体物理和系统动作）。
- **MCP (Model Context Protocol)**: 标准化的模型上下文协议。使得代理能够弹性、动态且安全地接入外部上下文、底层数据和企业服务。
- **Skill (技能)**: 特定领域的行为准则与工作流规范。框架将专家级的行为协议注入 LLM 的提示词中，以强制约束并引导其产出符合领域最佳实践的结果。
- **Agent (子代理)**: 自主或半自主的子系统。对于长时间运行、高度专业化或松耦合的任务，底层引擎会调度专门的模块化子代理去处理。

## 3. 架构意义
通用代理框架定义了 AI 如何从“被动的文本生成器”转变为“主动的系统操作员”。它承载了企业核心战略 (Strategy) 与业务落地 (Business) 的转换，为不同领域的业务应用层 (AgentApplication) 提供了一套标准的 AI 能力集成范式。
